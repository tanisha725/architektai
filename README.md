# ArchitektAI

> Design systems. Understand decisions. Build with confidence.

An AI-powered system design generator and learning platform. Describe a product idea, and it produces a structured, explained system design — requirements, scale estimates, architecture, database/API design, trade-offs, failure analysis, and an implementation roadmap — plus an interview mode that quizzes you on the design it generated.

This project is being built incrementally and documented in [learning.md](./learning.md) as it goes.

## Tech stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- React Flow (interactive architecture diagrams)
- PostgreSQL + Prisma
- LLM API with schema-validated structured output

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
